Фокус: при открытии фокус переходит на первый подходящий элемент либо на явно указанный, для подтверждения опасного действия по умолчанию на безопасную кнопку. Tab и Shift+Tab циклически ходят только внутри модального окна. При закрытии фокус возвращается элементу, который имел его до открытия, если он ещё существует и доступен; иначе применяется документированное правило. Вложенные модальные окна образуют стек: ввод получает верхнее, Escape закрывает по одному, фокус возвращается по цепочке, overlay не затемняется многократно без необходимости.
