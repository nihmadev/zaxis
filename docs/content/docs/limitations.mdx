---
title: Limitations
icon: CircleSlash
description: Supported scope and boundaries of the 0.0.3 Genetic development release.
---

| Area | Current boundary |
| --- | --- |
| Native windows | Built-in runner opens several native windows (`WindowPlan`, `Windows`), each with its own `Context` and surface over shared glyph, image and appearance resources; no native menus or tray icons; window geometry is not persisted |
| Backends | winit and wgpu are always dependencies; no optional backend feature flags |
| Browser | `wasm32-unknown-unknown` on WebGPU or WebGL2, one canvas and one window per page; no system fonts, file paths, threads, IME composition or native chrome; a lost WebGL context is not recovered; Chrome only was checked. See [Web](./web.mdx) |
| Layout | Rows, columns, Grid and Table; `ScrollArea::show_rows`, `TreeView`, `ComboBox` and `ListBox` virtualize fixed-height rows, and `ListBox` also supports measured (variable-height) rows with estimates until a row is built; `Table::show_rows` is still fixed-height |
| Controls | TextEdit (single-line and multi-line text area), ComboBox/Popup, numeric controls, ColorPicker, ScrollArea, Grid, Table and Image are available; menu bar with cascading submenus (`MenuBar`), `Toast`, `KeyBox`, `IconTabs`, `Badge`, `ListBox` (virtualized, key-based selection; no columns, horizontal scrolling or in-place editing) `SegmentedControl` (single selection only; labels truncate or collapse to icons instead of wrapping) and `Carousel` (stack of cards or photo slider; clips content to a rectangle inside the rounded outline because the renderer has no rounded clip; tilted and scaled layers are look-only for input) |
| Text | Complex shaping, bidirectional layout, ligatures, color emoji and one font weight per string are available; `RichText` spans (`rich_label`, `SelectableLabel::rich`) mix weight, monospace, color, underline and links inside one wrapped paragraph, but the list is flat (no nesting) and the size is one value for the whole text; plain `Text` and `TextEdit` still have one style per string; no italic, optical sizes, extra OpenType features or CSS-like font selectors; no syntax highlighting; monospace text is one cell per character only for the primary font (fallback CJK and emoji keep their own advance and shift the rest of the line), tabular figures need a font with `tnum`, and code ligatures are off; the multi-line TextEdit has no line numbers, syntax highlighting, rich text, multiple carets, search, folding or completion |
| Fonts | Bundled Inter in Regular, Medium, SemiBold and Bold (`bundled-weights`), bundled JetBrains Mono for monospace text (`bundled-monospace`; replaceable with `RunOptions::with_monospace_family`), a custom `FontFamily` through `RunOptions::with_font_family` or `Context::with_fonts`, system fallback and bundled color emoji; weights without a file use the nearest one and are never synthesized; variable-font axes are not used (cosmic-text 0.17 shapes them inconsistently); fallback fonts follow the weight only where they have that file; no runtime font setter, glyph eviction, or italic |
| Static text selection | `SelectableLabel`, `Hyperlink` and `rich_label` select by grapheme cluster, copy exactly the selected text and group into a `SelectionScope`; one selection per native window, none across windows; in a virtualized list only the rows that were built are selected and copied; a range crossing a direction change in bidirectional text is a set of rectangles, not a visually reordered span; the library never opens an address unless `open_in_browser` is requested, and then only `https`, `http` and `mailto` unless the allowlist is extended |
| Toasts | `Toast` stacks in the bottom-right corner of the window that shows it; passive: no focus, pointer input or actions; announced to screen readers as a polite status region |
| Accessibility | AccessKit tree on Windows (UI Automation) and macOS (NSAccessibility); Linux and BSD AT-SPI only with the `accesskit_unix` feature; none in the browser or on mobile. No drag-and-drop requests; virtualized rows that were not built have no node; in `RadioGroup` and `SegmentedControl` only the current tab stop accepts a focus request; built-in names such as "Close", "Menu", "Resize", "Previous", "Next", "Page N", "Copy" and "Hue" are English only; tab panels are linked to their tab by build order; `TitleBar` follows the content in tree order; no password field; `Card` has no name API. Checked with tests, a UI Automation client and Narrator on Windows 11; NVDA, JAWS, Accessibility Insights, VoiceOver and Orca were not tried. See [Accessibility](./accessibility.mdx#limitations) |
| Modal dialogs | One input target at a time (the newest open modal); no system file dialogs, dragging or resizing of the modal, or library-side dialog queue; a modal covers only its own native window, and an OS close request goes to `App::close_requested`, where `CloseRequested::reject` keeps the window open for a "Save changes?" modal; `Floating` `ColorPicker` and `Window` panels inside a modal are shown inline or stay below it; windows narrower than about 200 px can push a two-button action row past the edge |
| Window state | Geometry retained by ID, with initial-position/size builders; no public reset, forced reposition, or forced resize method |
| Custom interaction | External widgets get a `Response` for their own rectangle with `Ui::interact` and a `Sense` (hover, click, drag, focus); there is no public hit-region type, text editing or IME for custom widgets, and a focused widget reads raw keys from `InputState` |
| Drag and drop | In-window drag and drop of in-process typed payloads between components of one `Context`; no OS file drag, clipboard drag, transfer between native windows (each has its own `Context`) or processes, OLE, or dragging selected text |
| Renderer integration | Renderer owns its surface, device, and queue; no public render-into-existing-pass API |
| Antialiasing | Automatic 4× MSAA when supported, otherwise 1×; no public override |
| Texture upload | Complete image payloads, full uploads on revision change; no public dirty-region API |
| Memory | Window/scroll states and glyph atlas pages remain for the context lifetime; GPU buffers grow without shrinking |
| Persistence | Application stores and loads its own model; library does not serialize UI or application state |
| Images | Local files, bytes and RGBA pixels; no built-in network fetching, animated playback, or external SVG resource loading; in a browser no file paths, and decoding runs on the drawing thread in per-frame slices |

zaxis `Window` panels are not native OS windows. Opening several panels does not
create several event loops or GPU surfaces. Native windows come from the runner's
`WindowPlan` / `Windows` API; see [Desktop runner](./app.mdx#multiple-windows).

TextEdit supports grapheme-aware editing, clipboard operations, undo/redo, and
native IME preedit/commit, in one line or in a multi-line text area. Bidirectional text is
edited in logical order with per-run selection rectangles, not a full visual-navigation
model. The text, caret and selection are exposed to assistive technology; see
[Accessibility](./accessibility.mdx#text-and-ime).

The repository targets desktop tools, and the runner also builds for the browser (see
[Web](./web.mdx)): one canvas, WebGPU with a WebGL2 fallback, and the differences listed
there. Browser support is new; only Chrome has been tried, and Firefox, Safari, mobile
browsers and input methods are unchecked.
